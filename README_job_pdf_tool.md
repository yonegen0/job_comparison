# 求人PDF整理ツール

`ダウンロード`直下の文字入り求人PDFを、外部サービスへ送信せずにCSV化・リネームするWindows向けツールです。PDF本文やファイル内容は変更しません。

## セットアップ

Python 3.13の`py`ランチャーを使用します。

```powershell
py -m venv .venv
.\.venv\Scripts\Activate.ps1
py -m pip install -r requirements.txt
```

依存パッケージの取得時だけインターネット接続が必要です。PDF処理中の通信、OCR、LLM、クラウドAPI利用はありません。

## 事前確認

```powershell
py job_pdf_tool.py --input ".\ダウンロード"
```

事前確認ではPDF、CSV、レポートを変更しません。対象数、CSV出力対象数、CSV除外数、状態、旧名から新名への対応を表示します。終了コード`2`は、未記載項目、警告、必須項目による除外、改名保留、またはPDF未検出の既存CSV行があることを表し、プログラム異常ではありません。

## 本実行

```powershell
py job_pdf_tool.py --input ".\ダウンロード" --apply
```

入力フォルダに次を出力します。

- `求人情報.csv`: 会社名と募集ポジションを確定できたPDFだけの求人情報
- `処理レポート.csv`: 除外PDFを含む全PDFの欠損、矛盾、抽出方法、旧名・新名、SHA-256

Jobins形式のPDFでは、`採用企業名`（ない場合は`会社名`）と`職種分類（中分類）`の全文をCSVへ出力します。PDFは、そのCSV行と同じ値から作った`会社名（募集ポジション）.pdf`へその場で変更します。求人名の自動短縮は行いません。

会社名と募集ポジションは必須です。PDF本文の認識済み見出しから両方を取得できないPDFは、`求人情報.csv`とリネーム処理から除外します。除外PDFは移動・削除せず、元の名前と内容を維持し、理由を`処理レポート.csv`へ記録します。その他15項目の未記載は除外理由にならず、`記載なし`を出力して部分成功として扱います。

`職種分類（中分類）`に複数の分類が読点区切りで記載されている場合は、先頭だけに絞らず全文を使用します。Jobins形式で中分類を取得できないPDFは求人名へフォールバックせず、CSV・改名対象から除外します。ファイル名だけにWindows禁止文字変換とパス長制限を適用します。

`--output-csv`を省略した場合、入力フォルダ内に`求人情報*.csv`が1件だけあればそのCSVを更新し、なければ`求人情報.csv`を作成します。複数ある場合は誤更新を避けるため`--output-csv`で対象を指定してください。既存CSVにしかない行は削除せず、`処理状態`を`PDF未検出`として保持します。追加列も引き継ぎますが、現在存在するPDFの標準列はPDF本文から再生成します。

同じ会社名と中分類を持つPDFが複数ある場合は、全件に求人IDまたはSHA-256由来の識別子を付けます。上書き、同名衝突、パス長超過を避け、途中失敗時はPDFとCSVを元へ戻します。

## 未取得項目の再取得

初回抽出で`記載なし`になった会社名、募集ポジション、その他15項目は、項目ごとにPDFを読み直して追加で最大3回再取得します。初回を含めると1項目あたり最大4回の評価になります。初回から取得できた項目は再取得や上書きを行いません。

再取得は項目ごとに独立しています。例えば給与の再取得中に残業時間も読み取れていても、給与以外の結果は採用しません。処理レポートには途中の失敗や「何回目で成功したか」は追加せず、各項目の最終結果だけを記録します。3回後も取得できない場合は、任意項目は`記載なし`、会社名・募集ポジションはCSV・改名対象外とする従来の動作を維持します。

再取得でも同じローカル抽出ルールを使い、見出しの推測範囲やJobins用の制限は緩めません。そのため、恒常的な抽出ルール不足による欠損は通常は解消しません。また、17項目すべてが未取得の場合は、1PDFあたり初回を含め最大52回の全文読込みと解析を行うため、処理時間が増えることがあります。この再取得は事前確認と`--apply`の両方で実行されます。

## 別見出しの追加

UTF-8 JSONで正規項目ごとに追加の見出しを指定できます。内蔵見出しは削除されません。Jobins形式の会社名と募集ポジションは、安全のため前述の専用見出しを固定で使用します。追加見出しは主に汎用PDFで使用します。

```json
{
  "会社名": ["雇用主"],
  "募集ポジション": ["採用職種"],
  "勤務時間": ["勤務帯"]
}
```

```powershell
py job_pdf_tool.py --input ".\ダウンロード" --aliases ".\aliases.json"
```

## 対応外PDF

スキャン、暗号化、破損、会社名・職種を見出しから特定できないPDFは、求人情報CSVと改名処理から除外します。PDFは元の状態で残し、除外理由だけを処理レポートへ記録します。

## 復旧

通常の途中失敗は自動でロールバックされます。万一ロールバックに失敗した場合は、エラーメッセージと`処理レポート.csv`の`元ファイル名`・`新ファイル名`を使って手動で戻してください。
