# 求人比較ツール 0.4.3

転職者条件の入力、JoBins／CareerBankの保存済み検索結果HTML取込、求人PDFの整理、全文Markdown統合、10求人の比較資料PDF生成を、1つのWindows GUIで行う完全ローカルツールです。求人媒体、AI、外部サービスへ自動接続せず、ファイルを送信しません。

初めて利用する場合は、[画像付き使い方ガイド](docs/user-guide/求人比較ツール_使い方.md)を参照してください。架空データを使った画面キャプチャーで、ZIP展開から全6タブの操作まで説明しています。

## GUIの6タブ

1. 「転職者条件」: 年齢・性別・学歴と任意の職歴・資格を入力します。起動時はこのタブを表示します。
2. 「求人取得」: 保存済みJoBins／CareerBank検索結果HTMLを取り込み、媒体別CSV、直前状態、AI比較用ファイルを管理します。
3. 「求人PDF整理」: PDFを解析し、改名内容、`求人情報.json`、`処理レポート.json`を事前確認してから一括確定します。
4. 「求人PDF全文統合テキスト化」: 選択フォルダー直下のPDF本文を、境界マーカー付きの`output\PDF全文_統合テキスト化.md`へ統合します。OCR、要約、補正は行いません。
5. 「対象PDFコピー」: PDF名を1行1件で直接貼り付け、選択フォルダー直下の完全一致PDFを`対象pdf`へコピーします。同名は1件ずつ置換・連番での別名保存・キャンセルを選べます。
6. 「比較資料PDF生成」: 比較Markdownと元PDF対応JSONを照合し、A4縦12ページのPDF、検証済みMarkdown、検証結果CSVを生成します。

各工程の「事前確認」はファイルや`output`フォルダーを作成しません。本実行時も必ず最新状態をprepareし、確認後のPDF・JSON・旧CSV・Markdown変更は`CHANGED001`として停止します。

## 求人取得と既存データ

初回は「求人取得」タブの案内から初期設定を開始します。求人取得機能は、先頭の転職者条件タブを表示したままバックグラウンドで準備されます。独立版で作成済みの`%LOCALAPPDATA%\RecruitJobTool`をそのまま再利用し、旧版フォルダーから移行する場合も移行元を変更・削除しません。独立版が起動中の場合は求人取得だけを停止し、ほかの5タブは引き続き利用できます。

取り込み方法の「置換」は現在の同一媒体求人を今回のHTML内容で置き換えます。「追加・更新」は同一求人IDを更新し、新規求人IDを追加し、今回のHTMLに含まれない既存求人を保持します。選択した方法はJoBins／CareerBankごとにアプリ終了まで保持されるため、連続取り込み時に選び直す必要はありません。取り込み完了後は使用済みHTMLの選択だけを解除し、次回起動時は「置換」から開始します。100件超過状態、出力先設定エラー、利用不可状態では安全のため「置換」へ補正します。

求人取得のAI用JSONは`job-comparison-jobs-v4`です。PDF整理の`job-comparison/job-info`や比較資料用manifestとは別形式であり、自動変換・自動受け渡しは行いません。

## 転職者条件とAI比較

転職者条件は起動中のメモリにだけ保持します。`%LOCALAPPDATA%\RecruitJobTool`、保存求人、CSV、求人JSON、ログ、PDF工程には保存しません。条件付き比較の生成に成功した場合だけ、`job-comparison-v9`のMarkdownガイドへ読みやすい箇条書き・引用形式で記録されます。氏名、住所、連絡先など、判定に不要な個人情報は入力しないでください。

転職者条件タブでは、職歴・資格欄の上では各入力欄を、それ以外のカード・説明文・余白上では画面全体をマウスホイールでスクロールします。

必須3項目が入力済みなら、求人JSON v4と条件入りガイド v9を一括生成します。AIへは両ファイルを一緒に添付してください。条件が未入力の場合は毎回確認し、承認したときだけ従来の一般比較を作成します。一般比較のガイドは`job-comparison-v8`で任意となり、求人JSON単体でも利用できます。

ショートカットはCtrl+1～Ctrl+6で6タブを切り替えます。Ctrl+5は対象PDFコピー、Ctrl+6は比較資料PDF生成です。Alt+J、Alt+C、Ctrl+O、Ctrl+I、Ctrl+E、Ctrl+R、Ctrl+G、Ctrl+Shift+Oは「求人取得」タブだけで動作します。F5はPDF関連の4タブだけで事前確認を行います。

## 対象PDFコピー

コピー元を選び、拡張子を含むPDF名を1行1件で入力します。txt添付は不要です。HTML文字参照・前後空白は整形し、空行と重複を除きます。名前の大小文字を区別した完全一致で直下だけを検索します。「事前確認」後に「PDFをコピー」を押し、同名PDFごとの判断と最終確認を行います。別名は`名前 (1).pdf`形式です。未発見・不正入力・個別失敗は結果一覧へ表示し、存在する対象はコピーします。入力は起動中だけ保持します。対象外ファイルは削除しません。

## JSON出力と旧CSV移行

求人PDF整理の出力フォルダーを省略すると`<PDFフォルダー>\output`へ保存します。

- `求人情報.json`: `format`が`job-comparison/job-info`、`format_version`が`1`の求人情報配列です。標準20項目と既存追加項目を保持します。
- `処理レポート.json`: `format`が`job-comparison/processing-report`、`format_version`が`1`の処理記録です。

既存JSONには置換・別名保存・キャンセルを解析前に選びます。別名保存は2ファイルに同じ`(n)`を付けます。基準JSONがなく旧`求人情報.csv`が見つかった場合は、初回だけJSONへ取り込めます。CSVは変更・削除されません。

## 全文統合テキスト化とAI添付

「整理タブと同じフォルダーを使用」は、その時点の値を1回コピーします。その後の2タブは独立しています。空ページ、NUL置換、大容量は警告付き成功です。読取不能PDFが1件でもある場合は生成しません。

`求人情報.json`と`PDF全文_統合テキスト化.md`を別AIへ添付する場合は、Markdownの`source_file`とJSONの`新ファイル名`を照合してください。JSONの求人配列は`jobs`です。値がない場合は推測せず`記載なし`とし、既存値を不用意に上書きしないでください。

## CLI

```powershell
py job_pdf_tool.py --input "C:\求人PDF" --output-json "C:\出力\求人情報.json" --report-json "C:\出力\処理レポート.json"
py job_pdf_tool.py --input "C:\求人PDF" --apply --import-main-csv "C:\旧\求人情報.csv"
```

既定はdry-runです。旧`--output-csv`と`--report-csv`は廃止されました。比較資料CLIの検証結果CSVは従来どおりです。詳細は`README_job_pdf_tool.md`と`README_job_comparison_report.md`を参照してください。

## 配布

- EXE: `JobComparisonTool.exe`
- ZIP: `release\JobComparisonTool-0.4.3-win-x64.zip`
- checksum: `release\SHA256SUMS-0.4.3.txt`

比較資料PDF生成にはEdgeまたはChromeが必要です。配布物には画像付き使い方ガイドを同梱しますが、実求人PDF、求人データJSON、CSV、生成Markdown、manifest、単体Exporter EXEは含めません。

### 初回起動と配布時の案内

現在の配布exeは未署名です。ファイル単位のブロック解除と、警告が残る場合の操作を案内しますが、警告の非表示を保証するものではありません。基本の起動方法は`JobComparisonTool.exe`のダブルクリックです。既存の「求人比較ツールを起動.bat」も利用できます。

以下をZIP送付時の本文へコピーし、展開前に読めるようにしてください。

> 自分が利用する予定のツールであり、信頼する配布元から受け取ったZIPであることを確認してください。初回は、ZIPを右クリックして「プロパティ」→「全般」を開き、「許可する」が表示されていればチェックし、「適用」→「OK」を押してください。項目がない場合はこの操作を省略します。その後、ZIPを書き込み可能な通常フォルダーへすべて展開し、JobComparisonTool.exeをダブルクリックしてください。
>
> すでに展開した場合は、元のZIPを解除して新しい別フォルダーへ展開し直してください。既存フォルダーは削除・上書きせず、保存データを残してください。ZIP内から直接起動したり、exeや_internal、起動用BATを個別に移動したりしないでください。
>
> 「Windows によって PC が保護されました」と表示された場合は、「詳細情報」でアプリ名がJobComparisonTool.exeであることを確認し、信頼する配布物であれば「実行」を選んでください。「実行」が表示されない会社・組織のPCでは管理者へ確認してください。それ以外のPCや、別の検出・ブロック画面が出る場合は、表示内容を配布担当者へ伝えてください。
>
> ブロック解除は安全性やウイルス検査済みであることを保証する操作ではありません。「許可する」がない場合も安全判定済みとは限りません。解除後も警告が残る場合があります。

詳細は[使い方ガイドの「利用前の準備」](docs/user-guide/求人比較ツール_使い方.md#2-利用前の準備)を参照してください。
